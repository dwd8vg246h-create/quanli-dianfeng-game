⚠️ 能力边界
本后台管理的是云端档案库。玩家若处于离线状态（网络不通或尚未配置云端）， 其进度仅存在于本人设备的浏览器中，此处无法查看或处置。

序列、军种、学历、财政、健康等项取自存档摘要：玩家须重新上传一次存档 （打开游戏即自动同步）后才会出现，此前建档的老档案显示为"—"属正常。

口令校验在前端进行——纯前端页面无法真正保密。若需严格鉴权， 应在 Supabase 收紧 RLS 策略，或改用服务端接口（如 Edge Function + service_role）。
